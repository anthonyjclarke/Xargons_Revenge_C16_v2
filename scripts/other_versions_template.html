Xargon's Revenge: Versions Compared

Every copy found so far, decoded from its own bytes: aliens, landscape, font, title banner and ship. Generated by scripts/compare_other_versions.py.

Short answer. Game v1 and game v2 differ only in the alien graphics at $0400–$07FF. Code, landscape and font are byte-identical. The difference comes from a cassette loader that copies BJH wrongly: source +1 byte per page instead of +256. That leaves 4 alien designs, shifted up, where there should be 16.

The original 1985 release tape is game v2. At the game's entry ($1800) its aliens, landscape, code and font match game v2 byte for byte. Its own loader at $0C00 loads BJH unchanged to $0800 and then makes the faulty copy, so v2 is what Gremlin shipped.

The downloads split into the same two families. The disk version and the loading-picture disk hold your BJH unchanged and copy it correctly (v1 aliens). The original release tape, the C16 Classics II tape and the running version show the tape-copy aliens (v2). The early stages file is an earlier development build with no aliens, your LANDSCAPE-1 and a different font. No copy shows signs of someone else redrawing graphics. Apart from the early build's font, every graphic traces back to a file on your 2026 Side 2 disk.

Screens

VICE (C16 PAL, -TEDfilter 0) running each copy as it is. Both tapes load with Novaload (serial A100001); the original's loading screen says "ZARGON REVENGE", the compilation's "XARGONS REVENGE". The title screens are the same game. Background and land colours are picked at random per run. The early build has a different scroll text and the older landscape.

Aliens

Each wave copies one 64-byte entry into characters 213–220: two frames of a 2 × 2 character block. Rows are sheets 1–16; columns are copies. A red outline marks an alien that differs from your BJH. Colours are illustrative (the game picks a random hue).

Landscape Bank

256 multicolour characters at $1000, drawn with the gameplay colours. Two banks exist across all copies, and both are files on your 2026 Side 2 disk. Glyphs outlined in red differ between them.

Font Bank

256 hires characters at $3800. Every copy except the early build has FRAK! exactly. The early build differs in the glyphs outlined: a different alphabet (codes 64–101), fuel-bar glyphs (106–123) and solid blocks where the aliens would later go (213–255).

Title Banner and Ship

Both are tables inside the code. They are the same bytes in every copy that has them; only their addresses move.

Notes Beyond Graphics

  • Loading-picture disk, P3. Same graphics, but the code is a different revision (11 bytes shorter). TOKILL is 32, 40, 48, 56, 64, 72 aliens per level instead of 24, 24, 32, 32, 48, 48, and the "first sheet: only 16 aliens" special case in SET-SHEET is missing. Everything after it moves 11 bytes. Its LOADER, P1 and P2 are byte-identical to your Side 1 disk, so this looks like a fuller copy of the same disk. P3 is either an earlier build from before the difficulty was eased, or a later one where it was raised. The bytes don't say which.
  • Tape loader. The original release, the Classics II tape and the running version carry the same 96-byte loader at $0C00, byte for byte. It reads P1–P4 from the cassette, and its INC $0C34 bumps the low byte of the source address. Tracing the original tape in VICE catches it writing the second alien page with LDA $0801,X / STA $0500,X. The loading-picture disk's loader has the same structure for device 8 and correctly bumps both high bytes (INC $0371, INC $0374).
  • Original release and Classics II. At $1800 the two tapes differ from each other only in 7 bytes of screen RAM, and from the running version only in 19 and 12 screen-RAM bytes. The running version is a packed copy of the released game. The .vsf snapshot of the Classics II tape agrees with the tape, apart from bytes the game rewrites while running.
  • Disk version. Identical to game v1 in aliens, landscape, code and font. Only 50 unused bytes between the code end ($379E) and the font differ.
  • Early stages. About 80% of the code differs; tables appear about 2.1–2.6 KB lower. It has the title banner and the CHR87/CHR91 animations, but not the ship table at the later layout. Its scroller reads "Micro Projects 1985" rather than advertising Gremlin titles.

Appendix A: Download Sources

All six downloads are from the Plus/4 World entry for Xargon's Revenge. Each local file was checked on 22 October 2026 against the site's current download by SHA-256 (inside the ZIP, for the zipped ones). The original release tape was renamed locally from xargons_revenge.tap. The .vsf is not offered on the site: it is a VICE snapshot taken of the Classics II tape. The development copies trace back to my 1992 export in Mark Hardisty's Gremlin Graphics Archive (see docs/GREMLIN_ARCHIVE.md). The full list, with mirrors and the entries not yet examined, is in docs/OTHER_VERSIONS.md.

Method

Memory images: game v1/v2 from build/; the running version from VICE after decompression (build/reference-memory.bin); D64 files read with scripts/d64_image.py and placed as their own loaders place them; both tapes loaded in VICE (attached with -1, LOAD typed, datasette started with the monitor's tapectrl 1) and saved at the break on $1800; the .vsf RAM, from its PLUS4MEM module, only as a cross-check. Graphics are compared with BJH, LANDSCAPE-1, LANDSCAPE-2 and FRAK! from your 2026 Side 2 disk. The palette is docs/verification/ted-palette.json. No input file is modified.

SHA-256 of each input is listed in the summary table.
